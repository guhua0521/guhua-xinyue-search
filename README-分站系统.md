# 分站系统使用说明（SaaS 多租户版）

在网盘资源管理系统（xinyue-search v3.6）基础上扩展的**一键开通分站**功能。
一套代码、一个数据库即可运营主站 + 无数分站；每个分站绑定独立域名、拥有独立后台，
后台仅可修改网站图标、网站广告、名称等基础配置，**不能设计/修改 API 接口**，
搜索、转存、排行榜等核心功能完全继承主站。

---

## 一、功能清单

### 主站（超级管理员）
- 「系统 → 分站管理」一键开通分站：填分站名称、绑定域名即可，自动生成
  分站、基础配置、管理员账号密码、后台地址；
- 分站列表：搜索、编辑（改域名/到期时间/状态）、禁用/启用、重置密码、删除；
- 到期时间管理：到期自动停用，前台显示"分站已停用"提示页；
- 命令行开通：`php think site:create --name=... --domain=...`。

### 分站（分站管理员）
- 独立后台登录地址：`http://分站域名/qfadmin/admin/login`；
- 菜单仅保留「概况 + 基础设置」，可修改：
  - 网站名称、宣传语、LOGO、网站icon、顶部外链、群二维码、底部介绍/版权；
  - **7 个广告位**：首页顶部/底部、搜索列表顶部/底部、详情页顶部/底部、页脚广告；
  - 首页背景图/背景色/主题色/文字色/自定义CSS；
  - SEO标题/关键词/描述、统计代码、搜索无结果提示；
- **不能**：修改接口配置、转存账号/Cookie、资源管理、参数配置等，越权访问一律 403。

### 多后台同时登录
- 每个后台的登录会话**互相独立**（登录 Cookie 按分站区分），主站后台、各分站后台可以同时登录、互不挤掉；
- 正式部署时各分站使用独立域名，浏览器按域名自动隔离会话，天然互不影响；
- 同一主机测试（如 `127.0.0.1`）时，通过分站标识切换：
  - 打开 `http://主机/qfadmin?site=分站标识` 进入该分站后台；
  - 打开 `http://主机/qfadmin?site=main` 回到主站后台；
- 分站后台右上角头像菜单里有「主站后台」快捷入口，可一键切回。

### 前台（分站访问者）
- 完全继承主站功能：本地资源搜索、全网搜、排行榜、详情、提交需求等；
- 自动加载该分站自己的名称、图标、广告、样式，主站内容不受分站影响。

## 二、部署（新装）

0. PHP 版本按原教程选择 **7.2**（其它版本原程序不兼容；如需新版 PHP，见第五节）；
1. 上传源码到服务器；
2. 设置网站运行目录为 `public`；
3. 设置 ThinkPHP 伪静态；
4. 访问 `https://你的域名` 按向导安装（数据库表前缀填 `qf_`）；
5. 安装完成后用安装时创建的超管账号登录后台，
   进入「系统 → 分站管理」即可一键开通分站。

> 新版安装包已包含分站所需数据表与菜单，无需额外执行 SQL。

---

## 三、老站升级

已有 v3.6 站点升级为分站版：

1. 用新版源码覆盖（保留 `public/install/install.lock` 与 `.env`）；
2. 在数据库中执行升级脚本：`upgrade/site.sql`（可重复执行）；
3. 清理缓存（后台右上角「清除缓存」或删除 `runtime` 目录）；
4. 完成。

升级脚本会新增：
- `qf_site` 分站表、`qf_site_conf` 分站配置表；
- `qf_admin.site_id` 字段；
- 7 个广告位配置项（主站后台「基础设置」中也可直接配置）；
- 「分站管理员」用户组与「分站管理」菜单。

## 四、使用说明

### 1. 一键开通分站（后台页面）
主站后台 → 系统 → 分站管理 → 「一键开通分站」：
- 分站名称、绑定域名必填；分站标识留空自动生成；
- 到期时间留空为永久；管理员账号/密码留空自动生成；
- 开通成功后弹窗显示「前台地址 / 后台地址 / 账号 / 密码」，可一键复制全部信息。

### 2. 命令行开通（服务器运维）
```bash
php think site:create --name=XX资源站 --domain=ziyuan.example.com
php think site:create --name=XX资源站 --domain=ziyuan.example.com --account=site01 --password=abc123456 --expire=2026-12-31
```

### 3. 域名绑定
- 把分站域名（如 `ziyuan.example.com`）解析到本服务器（A 记录/CNAME），自动生效；
- 同一服务器、同一站点运行目录即可，无需为分站单独建站。

### 4. 本地测试
无域名时可通过标识访问：`http://服务器IP:端口/?site=分站标识`
（首次访问后浏览器会记住，同浏览器后续免带参数）。

### 5. 分站管理员操作
1. 打开分站后台地址，用开通时生成的账号密码登录；
2. 进入「基础设置」修改名称/图标/广告等，保存即对分站前台生效；
3. 修改密码在右上角头像下拉菜单中。

### 6. 后台会话与切换
- 每个管理员登录后各自保存独立会话，主站与分站后台可同时在线；
- 在同一台机器（同一域名/端口）测试时，切换后台：
  - 分站后台 → 主站后台：右上角头像菜单「主站后台」，或访问 `/qfadmin?site=main`；
  - 主站后台 → 分站后台：访问 `/qfadmin?site=分站标识`（在「分站管理」列表里可看到每个分站的标识）。

## 五、PHP 版本说明

- 原程序在 `public/index.php` 中限制了 PHP 版本（7.2~7.3），按原教程部署请直接使用 PHP 7.2；
- 若服务器只有 PHP 8.x，可注释 `public/index.php` 第 16~17 行版本判断，
  同时框架已内置一行 PHP 8.4+ 兼容补丁（`vendor/topthink/framework/src/think/initializer/Error.php`），
  8.x 下经实测可正常运行（可能有少量弃用提示，不影响功能）；
- 分站系统本身所有新增代码兼容 PHP 7.2。

## 六、分站可编辑配置白名单

`app/service/SiteService.php` 中 `$editableKeys` 定义了分站可编辑的全部配置，
如需开放/收回某项，改该数组即可（改动后删除 `runtime/cache` 生效）。

| 分类 | 配置项 |
| --- | --- |
| 基础信息 | app_name、app_subname、logo、app_icon、app_links、qcode、footer_dec、footer_copyright |
| 广告位 | ad_home_top、ad_home_bottom、ad_list_top、ad_list_bottom、ad_detail_top、ad_detail_bottom、ad_footer、ad_popup_enable、ad_popup_title、ad_popup_image、ad_popup_content、ad_popup_link、ad_popup_btn |
| 前端样式 | home_bg、home_background、home_color、home_theme、other_background、home_css |
| SEO | app_title、app_keywords、app_description、seo_statistics |
| 搜索提示 | search_tips、search_bg |

接口配置（api_list）、网盘 Cookie、转存目录、搜索线路等**不在此白名单内**，
分站无法查看与修改，完全由主站统一管理。
